# logs/

CC와의 대화 중 발생한 중요 결정, 아키텍처 선택, 트러블슈팅 메모를 저장하는 디렉토리.

git history나 코드에서 추론할 수 없는 "왜 이렇게 결정했는가"를 기록한다.
장기 기록은 roadmap.md의 개발 히스토리 섹션으로 이동한다.

## 파일 네이밍

```
YYYY-MM-DD_{주제}.md
예: 2026-04-19_phase1-decisions.md
```

## 기록 대상

- 여러 선택지 중 하나를 고른 이유
- 포기한 접근법과 그 이유
- 예상치 못한 문제와 해결 과정
- 다음 대화에서 기억해야 할 컨텍스트
